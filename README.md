# 🎬 Movie Review Sentiment Analysis using BERT

## 📌 Project Overview
This project performs **Sentiment Analysis on Movie Reviews** using **BERT (Bidirectional Encoder Representations from Transformers)**, a state-of-the-art Natural Language Processing (NLP) model.
The objective is to classify movie reviews as **Positive** or **Negative** based on the sentiment expressed in the review text. The project demonstrates the application of transformer-based deep learning models for text classification tasks.
---
## 🚀 Features
* Sentiment classification of movie reviews
* NLP text preprocessing
* Fine-tuning of BERT for sentiment analysis
* Prediction on custom user reviews
* Evaluation of model performance
* Jupyter Notebook implementation for easy experimentation

## 📊 Dataset
The project uses a movie review dataset containing textual reviews and corresponding sentiment labels.
Dataset files included:
* `large_movie_dataset_full.csv`
* `sample_input_dataset.csv`
The dataset is used to train and evaluate the sentiment classification model.
---
## 🔍 Methodology
1. Load movie review dataset
2. Perform text preprocessing
3. Tokenize text using BERT tokenizer
4. Convert text into embeddings
5. Train/Fine-tune BERT model
6. Predict sentiment labels
7. Evaluate model performance
